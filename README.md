# 🎬 소설 원작 영상화 작품의 언론 뉴스 보도량과 대중 검색 관심도의 상관관계 분석

## 1. 프로젝트 소개
문학 원작 소설이 영화나 드라마로 각색되어 미디어에 보도될 때, 대중의 실시간 검색 관심도가 어떻게 변화하는지 분석하는 Streamlit 웹 대시보드 프로젝트입니다.  
영문학의 원작 텍스트/서사 분석 역량과 미디어커뮤니케이션학의 미디어 프레임·여론 분석 역량을 결합하여, 네이버 뉴스 보도량과 네이버 데이터랩 검색 관심도 시계열 데이터를 시각화하고 상관관계 및 시차(Lag) 효과를 파악합니다.

## 3. 실행 방법 (How to Run)
```bash
# 1. 저장소 복제
git clone https://github.com/[내아이디]/[저장소이름].git

# 2. 프로젝트 이동
cd [저장소이름]

# 3. 필수 라이브러리 설치
pip install -r requirements.txt

# 4. Streamlit 앱 실행
streamlit run app.py
```
# 4. 사용 라이브러리

- streamlit: 대시보드 웹 애플리케이션 프레임워크
- pandas: 일별 보도량 및 검색 지수 시계열 데이터 가공, Outer/Inner Join 및 Lag 계산
- numpy: 시계열 통계 데이터 연산 및 난수 생성
- plotly: 이중 Y축(Dual Y-Axis) 기반 다중 선 그래프 시각화
- requests: 네이버 Open API (뉴스 및 데이터랩 트렌드) HTTP 통신
